# The Practice Book

곡을 듣고, 코드와 멜로디를 적고, 분석하는 연습장 — 리얼북 스타일의 곡 분석 시트를 브라우저 하나로.

`chord-sheet.html` 파일 하나로 동작해요. 설치 없이 브라우저로 열면 돼요.

## 주요 기능

- **계정** — 아이디·비밀번호로 가입/로그인하면 내 시트가 서버(Supabase)에 저장돼 어느 기기에서든 이어서 써요. 로그인 전에는 예시 3곡만 보여요
- **로그인 상태 유지** — 한 번 로그인하면 브라우저를 닫았다 열어도 로그인돼 있어요(기본 켜짐). 끄면 그 탭을 닫을 때까지만 유지되고, 공용 PC용이에요. 마지막 아이디는 기억해서 미리 채워 줘요
- **Practice Book 홈** — 최근에 만든 시트, 시트 목록(검색·정렬), 새 시트. 편집 내용은 자동 저장
- **리얼북 스타일 시트** — 오선 위 코드, 4마디 단위 줄, 송폼(섹션)별 사운드·리듬·멜로디 메모
- **수정 모드** — 평소엔 잠금, ✎ 수정을 눌렀을 때만 코드·멜로디·메모 편집
- **코드 입력** — `C#m7 C#m7 (Cm7-Bm7) E E` 같은 일괄 입력, 텐션·슬래시 코드, `%`, `N.C.`
- **멜로디 오선 편집** — 클릭·키보드(A–G, 3–7 길이)·하단 건반 입력, 셋잇단음표, 화음, 붙임줄
- **재생** — 피아노·기타(클린/오버드라이브/통기타) 코드 + 멜로디(보이스/플루트 등), BPM·박자표 반영
- **드럼 · 베이스 자동 반주** — 팝/록/펑크/재즈 스윙/브러시 발라드/보사노바/셔플/왈츠, 워킹·투필 등 베이스 라인, 필인·섹션 다이내믹·스윙
- **해석(도수) 표시 + 해석 코멘트** — 세컨더리 도미넌트, 트라이톤 대리, 모달 인터체인지, 종지, 모드·전조 구간 자동 해석
- **해석 주석 번호** — 해석(도수)을 켜면 오선 아래 빨간 도수 옆에 논문 각주처럼 `(1)`, `(2)` 번호가 붙어요. 번호를 누르면 그 코멘트 하나만 팝업으로 떠요(✕·바깥 클릭·Esc로 닫기). 한 코드에 코멘트가 여럿이면 `(1,2)`처럼 묶여요
- **해석 순위** — 음계 밖 코드가 여러 가지로 읽힐 때(세컨더리 도미넌트, 대리 코드, 모달 인터체인지, 디미니시…) 앞뒤 진행을 보고 가장 유력한 해석을 맨 위에, 나머지를 "다른 해석"으로 유력한 순서대로 보여 줘요
- **오선 줄 첫 마디** — 음자리표·조표 자리만큼 넓혀서 모든 마디가 코드·음표 공간을 똑같이 가져요(폰에서도 코드 이름이 겹치지 않아요)
- **코드표** — 672개 코드 프리셋(기본~재즈 텐션·얼터드), 필터, 클릭해서 듣기
- **같은 진행 찾기** — 도수(I, ii, V…) 기준으로 내 시트와 유명한 곡을 찾고 30초 미리듣기
- **레퍼런스 YouTube** — 링크를 누르면 팝업에서 바로 재생
- **🎬 원곡 싱크** — 레퍼런스 YouTube 영상과 시트 소리(코드·멜로디·드럼·베이스)를 박자에 맞춰 같이 재생해요. 영상이 기준 시계라 영상을 멈추거나 넘기면 시트도 따라가고, 영상의 ▶만 눌러도 시트가 따라 재생돼요. **싱크 맞추기**에서 1마디 시작·마지막 마디 끝·섹션 시작을 영상 시간으로 정하면(영상을 틀고 그 첫 박에 ‘지금’), 그 사이는 영상의 실제 템포로 늘이고 줄여 맞춰요
- **멜로디 색** — 오선 음표와 건반에서 멜로디를 그 순간 코드의 구성음(보라) · 곡의 스케일 음(파랑) · 스케일 밖 음(회색)으로 구분
- **하단 건반** — 지금 울리는 코드·멜로디·베이스 음을 하이라이트
- **파일 내보내기/불러오기** — 시트를 `.json`으로 백업·공유

## 사용법

`chord-sheet.html`을 브라우저(Chrome 권장)로 열기.

- 악기 샘플(FluidR3 사운드폰트), 미리듣기, YouTube는 인터넷 연결이 필요해요. 오프라인이면 합성음으로 재생돼요.
- 파일을 더블클릭해서 열면(`file://`) YouTube 정책상 영상이 작은 새 창으로 열려요. 웹 주소(http/https)로 열면 앱 안 팝업에서 재생돼요.
- 원곡 싱크는 웹 주소(https)로 열었을 때만 돼요(`file://`에서는 YouTube를 넣을 수 없어요).
- 싱크 위치 자동 찾기: `python3 tools/sync_parse.py 시트.chordsheet.json --url <YouTube 주소>` — 원곡을 박자 단위로 분석해 시트의 코드와 맞춰 보고(DTW) 1마디·섹션 시작·끝 시간을 시트에 적어요. 필요: `pip install librosa soundfile yt-dlp`, ffmpeg
- 로그인하면 시트가 Supabase에 계정별로 저장돼요(행 단위 보안으로 본인 시트만 읽고 쓸 수 있어요). 홈의 **전체 백업** 또는 **파일로 내보내기**로 따로 백업할 수도 있어요.
- 아이디로만 가입해요(이메일 없음). 아이디·비밀번호를 잊으면 찾을 수 없어요.
- 로그인은 이 브라우저에 기억돼요. 잠깐 오프라인이거나 서버가 응답하지 않아도 로그인을 지우지 않고, 연결되면 자동으로 다시 로그인해요. 여러 탭을 열어 둬도 로그인 상태가 같이 맞춰지고, 로그아웃은 이 기기에서만 돼요(다른 기기는 그대로).

## 예시 곡 (퍼블릭 도메인)

- When the Saints Go Marching In — 전통 영가, 딕시랜드 스탠다드 (F major)
- Greensleeves — 16세기 잉글랜드 민요 (A minor, 도리안 색채)
- Drunken Sailor — 뱃노래 (D 도리안)
